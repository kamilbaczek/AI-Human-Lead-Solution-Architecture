# ADR self-review

Shared by `adr-create` and `adr-research-draft`. Run it on your draft before saving.

Read the core checklist at `checklist.md` in this folder, plus `checklist-rest-api.md` if the ADR is about a REST API (HTTP endpoints, routes, controllers) or `checklist-db.md` if it is about a data store (database, schema, migrations, SQL, NoSQL). Check your draft against them and fix every item that would be ❌ or ⚠️. Leave an item open only when the input genuinely cannot answer it; write `{TODO: ...}` for it instead of inventing content. Do not paste the checklist into the ADR.
